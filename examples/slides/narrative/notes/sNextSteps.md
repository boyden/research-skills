PATTERN: next steps / roadmap. Use it at the end of a progress talk: three time-boxed cards, the first one highlighted because it is the decision point.

Design rules shown: equal cards on one grid under a thin gray time arrow; a dark header with the timeframe (accent only for the first, the current priority); one icon, a short title and two bullets per card; the take-home line says what the plan depends on.

Icons: lucide/users, lucide/list-checks, lucide/code (ISC; code is MIT via Feather).

Illustrative example: a design example, not a real study. Placeholders (n = XX) stand where a real deck would put numbers from its own result tables.
