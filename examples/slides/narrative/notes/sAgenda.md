PATTERN: agenda / roadmap. Show it after the title, and again at each section start with that section highlighted, so the audience always knows where they are. Four to six sections; more is a table of contents.

Design rules shown: numbered rows; the current section has an accent numeral, black name, tint band and accent edge bar; the other sections are muted gray; one short subtitle per section, no bullets. Reuse the same geometry on every repeat so only the highlight moves.

Illustrative example: a design example, not a real study. Placeholders (n = XX) stand where a real deck would put numbers from its own result tables.
